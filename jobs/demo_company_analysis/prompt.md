企業について短い構造化分析を行い、JSON だけを返してください。

目的:
- 会社の概要を短く要約する
- 従業員数と給与の代表値を含める
- 参考文献を付ける

要求:
- Web 参照を使ってよい
- 参考文献は本文の主張を支えられるものだけを入れる
- 従業員数は可能なら連結ベースを優先する
- 給与は可能なら平均年収を優先する
- workflow の各項目を終えたら `${SUBCWD}/workflow_checklist.json` の対応項目を `true` に更新する
- 値が不確実な場合は `source_note` で限定や不確実性を書く
- `references` には URL を含める
- 最終応答は `output.schema.json` に従う JSON だけにする

制約:
- 明示された attachment と read path がある場合はそれも根拠として使ってよい
- 十分な根拠がない断定は避ける
